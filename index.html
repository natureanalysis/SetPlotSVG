How it works

  1. Paste sample lists on the left (one element per row); click "Add sample" to add more
  2. Click a number in the diagram to list its elements in the Results panel
  3. Pick a style then export SVG / PNG in one click
  4. Drag any label or number to reposition it; double-click to reset. Use "Find an element" to highlight where an item sits
  5. Tick "Area-proportional" so every region's area matches the number of elements it holds
  6. Use ↑/↓ on each list card to reorder groups; the Venn / UpSet views and exports follow the new order
  7. Optional: set an experimental group and colour on each card; the UpSet plot shows the colour swatch and group name on the right, and the Set size axis shows each sample's total

🔒 100% client-side, data never leaves your browser
